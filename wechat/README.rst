===========================
WeChat 微信公众号集成
===========================

为 Odoo 19 提供微信公众号（订阅号/服务号）集成：消息收发、自动回复、
自定义菜单、模板消息、群发消息与用户管理。

功能
----

**消息接收与自动回复**

- 回调服务器（URL 验证 + 明文/AES 安全模式消息解密），接收文本、图片、
  语音、视频、小视频、位置、链接七类消息及 subscribe / unsubscribe /
  CLICK / VIEW / 扫码等事件
- 关键字自动回复：精确 / 模糊 / 正则三种匹配，按优先级排序，支持文本、
  图片、语音、视频、音乐、图文六种回复类型
- 默认回复与关注回复（每公司各一条）
- 所有消息落库 `wechat.message.log`，按保留天数每日清理

**自定义菜单**

- 结构化菜单编辑（一级/子按钮，11 种按钮类型）
- 生成微信 API 格式 JSON，一键同步/删除远程菜单

**模板消息与群发**

- 模板消息注册表（模板 ID + 数据 schema），发送统计
- 群发消息（文本/图片/语音/视频/图文），支持按标签圈人，状态跟踪

**用户管理**

- 关注自动建用户（含场景二维码参数），取关自动更新状态
- 用户标签/分组，消息统计

**API**

- JSON-RPC 接口（`/api/wechat/mp/*`）：模板消息发送、用户列表、菜单推送、
  带参二维码、素材上传

安装
----

1. 容器内安装 Python 依赖::

    pip install wechatpy

2. 安装模块（依赖仅 `base`）::

    docker exec odoo odoo -c /etc/odoo/odoo.conf -d <db> -i wechat \
        --stop-after-init --workers=0 --no-http

配置
----

1. 公司表单 → 微信页：填入公众号 AppID / AppSecret / Token / EncodingAESKey
2. 将回调 URL ``/wechat/mp/webhook/<公司ID>`` 与 Token、AESKey 配置到
   微信公众平台「服务器配置」
3. 「测试连接」按钮验证凭证并刷新 Access Token

Access Token 统一由 `wechat.request` 抽象管理：缓存于系统参数，过期前
5 分钟缓冲，遇 40001/42001 自动失效重取并重试一次。所有出站调用（模板、
群发、菜单、用户信息）均经由此层，公司记录上的 token 字段仅作展示。
