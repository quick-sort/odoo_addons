# InfoHub RSS Channel — 业务需求

## 要解决的问题

让 InfoHub 能从 RSS / Atom feed 拉取新闻，汇入池子。

## 范围

**做**：

- 提供 `rss` 渠道类型
- 一个渠道轮询一个 feed URL
- 解析 RSS 2.0、RSS 1.0（RDF）、Atom 三种布局
- 入库前可对条目求值 `filter_domain`
- 出网 SSRF 防护（复用 core 的 `url_guard`）

**不做**：

- 不做每发布方定制的解析（解析保持通用，发布方私有字段原样保留，供过滤用）
- 不做正文全文抓取（那属于增强，不是汇集）
- 不下载附件 / 媒体

## 非功能要求

1. **安全**：出网必须过 `url_guard`，手工逐跳重定向校验，响应体积上限。
2. **容错**：feed 暂时打不开、日期格式异常，都不能让整个渠道崩；可观测失败。
3. **离线可测**：测试 mock 所有 HTTP，无网络也能跑。
