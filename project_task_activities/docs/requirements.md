# Project Task Activities — 需求

## 问题

社区版 Odoo 没有「按项目查看所有任务活动」的入口。任务上的待办活动是
`mail.activity`，通过多态 `res_model_id`/`res_id` 挂到任务；只能逐个打开任务、
在其活动面板里查看。项目维度缺少一个汇总视图。

## 范围

- 在项目表单提供一个 smart button，显示该项目所有任务关联的活动数量。
- 点击后打开活动列表，范围严格限定为该项目的任务。
- 从项目进入任务视图时，在「Top Menu」embedded actions 里提供「Activities」入口，打开同一个列表。
- 覆盖所有挂在任务上的活动，无论活动类型。

## 不做

- 不引入独立的活动模型，不与其它待办/任务系统集成。
- 不改变任务上创建/管理活动的现有流程。
- 不统计项目记录本身（`project.project`）关联的活动。
- 不在汇总列表里提供新建/编辑/删除（避免产生与任务脱钩的活动）。
