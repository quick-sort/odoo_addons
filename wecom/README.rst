=====================
企业微信（自建应用）
=====================

在 Odoo 中管理企业微信自建应用：凭证配置、通讯录缓存、应用消息发布与撤回。

功能
====

- **应用管理**：按公司维护 CorpId / AgentId / Secret，access_token 自动获取、
  缓存并自动刷新（跨请求/跨 worker 复用）。
- **通讯录同步**：一键把企业微信的部门与成员拉到本地，发布消息时可直接选人。
- **消息发布**（三种类型，均支持成员/部门/标签/全员）：

  - 文本卡片 ``textcard``：单条 H5 链接卡片
  - 图文消息 ``news``：带缩略图，跳转外部链接
  - 图文素材消息 ``mpnews``：HTML 正文，在企业微信内直接阅读；
    封面图/正文图片自动上传素材

  超过 8 篇图文自动分批发送（企业微信单次上限 8 篇）。
- **发布历史**：每次发送留档（内容、接收范围、无效接收人、错误信息）。
- **消息撤回**：发送后自动记录企业微信返回的 ``msgid``，发布历史上一键撤回
  **24 小时内**发送的消息（企业微信会在接收人客户端删除该消息；
  "微信插件端"收到的消息不支持撤回——官方限制）。

其他模块对接
============

需要发企微应用消息的模块，一律调用::

    env['wecom.app'].browse(app_id).send_message(title, msg_type='textcard', ...)

它会自动创建发布历史并返回 ``wecom.app.message`` 记录，
通过 ``state`` / ``result`` / ``invalid_user`` 等字段检查发送结果。
不要绕过它直接调内部发送接口。

安装
====

- 依赖 Odoo ``base`` / ``web``。
- Python 依赖：``wechatpy``（需在 Odoo 运行环境中 ``pip install wechatpy``）。

配置
====

1. 安装模块后进入「企业微信 → 企微应用」，新建应用并填入 CorpId / AgentId / Secret。
2. 点击「同步部门」「同步成员」缓存通讯录（应用需有通讯录读取权限）。
3. 在「企业微信 → 发布历史」里新建消息、选择接收范围后点击「发布」；
   发送成功后如需撤回，在 24 小时内打开该条记录点击「撤回」。
