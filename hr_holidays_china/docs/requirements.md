# 需求与边界

## 背景

中国官方（国务院办公厅）每年发布下一年度《关于部分节假日安排的通知》，规定：

- **法定节假日 / 放假**：某些工作日放假（如元旦、春节、劳动节）。
- **调休补班**：为凑连休，某些周末被调整为上班日。

这些日期影响排程、工时、请假天数、制造排产等所有依赖 `resource.calendar`
的功能。手工维护容易出错、且每年要更新一次，因此需要自动同步。

## 目标

1. 从结构化的中国节假日数据源拉取某一年的安排。
2. 将「放假」写入公司级 `resource.calendar.leaves`（`time_type='leave'`），
   使这些日期被当作非工作日。
3. 将「调休补班」写入公司级 `resource.calendar.leaves`（`time_type='other'`），
   并让 `resource.calendar` 的工作时间计算把这些周末当作工作日。
4. 同步幂等：重复运行不产生重复数据。
5. 支持定时自动更新 + 手动触发。

## 范围边界

**做**：同步全国统一安排到一个公司的工作日历；放假与调休两类日期。

**不做**：

- 不处理企业自定义的额外假期/调休（已有 Odoo 原生「Public Time Off」界面可手工维护）。
- 不做农历/节气/法定年龄等数据。
- 不自动创建员工的 `hr.leave` 请假单（放假是公司级公休日，不扣员工额度）。
- 不处理多数据源/多国家；只针对中国大陆。
- 不负责数据源的合法性背书；数据源可配置，默认 holiday-cn。

## 关键需求点

- R1：可配置数据源 URL（含 `{year}` 占位符），默认指向 holiday-cn。
- R2：同步某一年，解析 `days` 列表中每条 `{name, date, isOffDay}`。
- R3：`isOffDay=true` → 放假；`isOffDay=false` → 调休补班。
- R4：每个公司每天最多一条记录（放假或调休），唯一键 `(company_id, date)`。
- R5：放假日期在日历中表现为 0 工时；调休日期表现为正常工作工时。
- R6：普通工作日、普通周末不受影响。
