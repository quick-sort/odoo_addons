# Project Task Meetings — 需求

## 问题

社区版 Odoo 没有「按项目查看所有任务关联会议」的入口。任务上的会议是
`calendar.event`，通过多态 `res_model_id`/`res_id` 挂到任务；只能逐个打开任务、
在其日历/活动里查看。项目维度缺少一个汇总视图。

## 范围

- 在项目表单提供一个 smart button，显示该项目所有任务关联的会议数量。
- 点击后打开会议日历，范围严格限定为该项目的任务。
- 从项目进入任务视图时，在「Top Menu」embedded actions 里提供「Meetings」入口，打开同一个日历。
- 覆盖所有挂在任务上的会议，无论来自「会议」活动还是会议表单的「文档」链接。

## 不做

- 不引入独立的会议模型，不与 Calendar 应用之外的日程源集成。
- 不改变任务上创建/管理会议的现有流程。
- 不统计项目记录本身（`project.project`）关联的会议。
- 不在汇总视图里提供新建/编辑/删除（避免产生与任务脱钩的会议）。
