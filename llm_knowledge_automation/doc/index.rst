=====================================
LLM Knowledge Automation (Deprecated)
=====================================

This addon is disabled and intentionally contains no automation models or
views. The former record/domain synchronization pipeline was removed during
the native ``llm.document`` refactor and no replacement automation API is
provided here.

Do not install this addon or use the former domain-sync fields and automated
actions. Use ``llm_knowledge`` for native file/URL documents. A future
record-driven integration must target ``llm.document`` explicitly.
