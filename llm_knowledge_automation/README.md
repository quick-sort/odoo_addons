# LLM Knowledge Automation (Deprecated)

This addon is disabled and intentionally contains no automation models or views.
The former record/domain automation pipeline was removed during the native
`llm.document` refactor and has not been replaced by a document automation API.

Do not install this addon and do not rely on the former domain-sync fields or
automated actions. Use `llm_knowledge` for native file/URL documents and build a
new integration against `llm.document` if record-driven synchronization is needed.
