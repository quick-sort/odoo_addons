# Web Gantt — 需求

## 问题

Odoo 企业版的 Gantt 视图不可用于社区版。需要一个通用的、可在任意模型上定义的
Gantt 视图，用于按时间轴查看有起止日期的记录。

## 范围

- 新增 `gantt` 视图类型，通过 `<gantt date_start="..." date_stop="..."/>` 注册。
- 时间尺度：周、月、季度、年（日尺度已移除）。
- 左侧列表 + 右侧时间轴的双栏布局，支持分组、横向/纵向滚动、缩放、今天标记。
- 左侧列表展示层级：有子记录的行显示折叠/展开箭头，可隐藏其后代行。
- 左侧列表在记录名后展示 assignee（由模型的 `get_gantt_data` 提供）。
- 行高较紧凑，便于一屏展示更多任务。
- 可编辑模式下拖拽任务条调整起止时间。
- 导出：CSV 明细；PNG 图片（整张图：全部行 + 完整时间范围）。
- 键盘与滚轮导航。

## 不做

- 不做日尺度视图。
- 不做依赖线、关键路径、资源泳道等企业版高级功能。
- 不做任务条拖拽缩放（只做整体平移改期）。
- 不在前端计算层级：层级与顺序由模型的 `get_gantt_data` 给出。
