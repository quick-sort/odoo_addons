# Project Task Documents — 需求

## 问题

社区版 Odoo 没有「按项目查看所有任务文档」的入口。任务上的文件都是
`ir.attachment`，只能逐个打开任务、在 chatter 里查看；使用「Document」活动类型
上传的文件同样如此。项目维度缺少一个汇总视图。

## 范围

- 在项目表单提供一个 smart button，显示该项目所有任务的附件数量。
- 点击后打开附件列表，范围严格限定为该项目的任务。
- 列表覆盖所有挂在任务上的附件，无论来自 chatter、直接上传还是「Document」活动。

## 不做

- 不引入独立的文档模型，不与 Documents（企业版）应用集成。
- 不改变任务上上传/管理附件的现有流程。
- 不统计项目记录本身（`project.project`）的附件。
- 不在汇总列表里提供新建/编辑/删除（避免产生与任务脱钩的附件）。
