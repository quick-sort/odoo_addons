LLM PostgreSQL pgvector Capability

Dense and sparse vector storage for databases managed by the LLM PostgreSQL control plane.

Composable capability

Use pgvector together with pg_search, pg_textsearch, and pgvectorscale in the same remote PostgreSQL database.

Dense and sparse vectors

Supports dense vector columns, sparsevec columns, exact search, HNSW, and IVFFlat configuration.

Remote data plane

Records are stored in a dedicated PostgreSQL database provisioned or adopted by llm_pg, not in Odoo's own database.

Detect-only extension policy

The module verifies that the vector extension is installed and usable. It never installs, upgrades, or removes PostgreSQL extensions.

Requirements: llm_pg, PostgreSQL with the vector extension installed in the target database, and suitable database privileges for schema and index creation.
